# ATLAS v0.1.0-alpha.21

ATLAS is an alpha release for Windows 10 or 11, x86-64.

## Nothing in the app changed

This release is the app as alpha.20 shipped it, built and checked by a faster release process. If you have alpha.20, updating changes nothing you will see; it is offered so that the next releases, which will change things, come out of the process this one tested.

## How releases are checked

- **Caches that are actually used.** Every Windows build used to save about 5 GB of caches under a separate name for each pipeline, more than the repository may keep, so each was thrown away before anything read it, and every build compiled the text-recognition libraries again (16 to 22 minutes) and spent up to 13 more uploading caches nobody used. One shared cache now holds the pinned runtime; every download in it is still checked by size and SHA-256.
- **The release ships what QA checked.** The release used to run every test and score the test documents with the real model again, on code its own preflight had already required to be byte for byte what QA ran. It now verifies that QA run - a successful run on main, at a commit with the same release inputs, with its evidence and the screenshot that was signed off - and builds, signs, smoke-tests, attests and publishes the installer from it. What it no longer does is run the unit tests a second time on those same sources.
- **The update over an earlier release is tested in QA.** Installing this version over alpha.14, as the in-app updater does, used to need a separate run before every release; QA now does it every time.
- **Pull requests run what they touch.** A change to documentation only runs no Windows build, a change to the window alone skips the Rust tests on Windows, and a draft skips the installer until it is marked ready. Everything runs on main and before every release.

Measured on the previous release, a pull request's checks took 57 minutes and a release about 3.8 hours of build machines end to end; this release is the first made the new way, and its runs are the first measurement of it.

## Updates

The installer is `Intern_0.1.0-alpha.21_x64-setup.exe`. Existing settings, queue records and model downloads are retained; upgrading from alpha.13 or later downloads no model.

The installer is **not Authenticode signed**. Windows may show a SmartScreen warning. Updater signatures, checksums and GitHub build provenance are verified before publication.
