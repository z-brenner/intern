# Intern v0.1.0-alpha.15

This is an alpha release for Windows 10 or 11, x86-64. Publication remains
blocked until fresh whole-product QA and capture review are complete.

## Changes since alpha.14

- **A smaller installed runtime.** Intern now packages only the upstream
  llama.cpp server used by both local models. Removing the unused PrismML
  build saves about 43 MB in the Windows installation. An update removes
  the obsolete runtime files; the model downloads are unchanged.
- **More stable model selection on Windows.** Memory planning credits the
  running server's measured working set instead of only a fixed estimate.
  A loaded 4B also needs 1 GiB of headroom above the 9B floor before upgrading.
  On measured Windows runner values, this prevents repeated 9B/4B swaps
  between queued documents. A genuinely full machine still uses the 4B;
  its provisional readings can wait longer before a 9B pass.

## Accuracy and limitations

The fifth held-out real-document set expands the evaluation to memoranda,
minutes and enforcement releases. On alpha.14's recorded 9B replies it scores
14 of 52 names right at the shipped review threshold, with two wrong names
among the four filed. This measurement is a limitation, not an accuracy gain.
Keep automatic renaming off until you have checked Intern on your documents.

The memory change was tested against measurements from GitHub-hosted Windows
runners, with unit tests reproducing the observed planning decisions. It has
not been measured in an installed app on a real laptop under memory pressure.
The 1 GiB upgrade margin may keep the smaller model loaded longer.

## Download and updates

The per-user installer is `Intern_0.1.0-alpha.15_x64-setup.exe`. Existing
alpha.14 clients use the same updater address and signing key
(`23576C5DEB2D7F57`). Queue, history, settings, learned spellings and downloaded
models are retained. New installations download the local models only when
requested. The local model keeps document text and prompts on the machine;
a hosted model, if enabled, receives distilled document text.

The installer is **not Authenticode signed**. Windows SmartScreen may warn,
and Smart App Control in enforcement mode may block installation. Verify
`SHA256SUMS.txt` and the GitHub build provenance before running it:

```sh
gh attestation verify Intern_0.1.0-alpha.15_x64-setup.exe --repo z-brenner/intern \
  --signer-workflow z-brenner/intern/.github/workflows/release.yml
```

Updater signatures, checksums, SBOMs and provenance are verified by the release
workflow before publication. This preparation does not publish a release.
