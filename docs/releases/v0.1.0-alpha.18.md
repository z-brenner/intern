# Intern v0.1.0-alpha.18

Intern is an alpha release for Windows 10 or 11, x86-64.

## Less memory, less waiting

- **The quicker model holds about 1.3 GB less memory while it is loaded.** Qwen3.5 4B now reads its weights where the model file lies instead of keeping a second copy of most of them, as the accurate model has since alpha.17. On a 16 GiB Windows test machine its memory after a document fell from 4,514 MiB to 3,215 MiB; on Linux test machines its peak fell from 4,558–4,613 MiB to 3,260–3,315 MiB. It is the model a computer with less than about 8 GB of memory free reads with, so the saving lands where memory is tightest. It also reads a little faster: about 9% on Linux test machines limited to the AVX2 code path, about 4% on the Windows test machine. It named as many test documents right as before (165 of 291, against 159 and 165 for two runs of the earlier launch).
- **After an update, Intern no longer reads its 7.8 GB of model files through again to check them.** A model file is checked again only when its size, its date or the checksum Intern pins for it changes. The model's short self-test still runs once after each update, before the first document, because an update can change how the model is asked and launched.
- **At sign-in, a model that has passed its checks is not loaded until a document is waiting for it**, so Intern holds no model's memory while there is nothing to read. A loaded model is no longer unloaded for being idle while a document waits to be read.
- **A document on its way starts the model loading**: one added, dropped or sent to Intern, one arriving in a watched folder on this computer's own disk or in a synced folder you chose as one only you add files to, and one that arrived there while Intern was off. The model loads while the file settles, so the reading can start sooner. A file a teammate adds to a shared folder does not load the model on every computer watching it. How much sooner was not measured: at most the model's load, about 3–5 seconds on a test machine with the file already in memory, more from a cold disk.
- **Faded single-page photos and faxes are recognised (OCR) up to four times sooner.** A reading that is plainly the right way up no longer tries the page at three other turns, none of which could have read it better. On eight such test images, 2.2–10.3 seconds became 0.7–2.6 seconds. Every one of the 448 development documents reads exactly as before.
- **Re-analyzing a file that has not changed reuses the text Intern has just read from it** (the last 8 documents, kept in memory until Intern restarts).

## Better readings

- **Scans that carry somebody else's OCR text are read again when that text would read badly**: every line repeated because the text was laid over the scan two or more times, or prose torn into a cell per word. Intern's own OCR reads such a page where it matters — a page it would read anyway, or the first two pages and the last — and its reading is used when it is confident (75 or more). On the 32 development documents with such a layer, the text Intern extracted held the right date for 26 where it held 22, and the right parties for 30 where it held 23. Those documents take longer to read: 0.5–5.5 seconds more on each of the 18 that read new pages, and up to a second less on 10 that now read a page once instead of twice.
- **A blank page in a scan — the back of a duplex sheet, a separator — is no longer a reason to send the document to review.** A page counts as blank only if it looks it: all but one pixel in 10,000 within a few shades of its paper. A page with faint writing, grain or bleed-through on it still raises the doubt it did.
- **In review, other parties the document names are one click from the name.** They are shown under the name; a click puts that party in place of the one the model chose (the second side of a "between" name). Only parties the document itself names are offered, never your own organization or someone only copied in. Choosing a party this way is not learned as a spelling to apply to later documents, and a document filed by party goes in the folder of the party you chose.

## Documents waiting for your check

From this release, Intern keeps with each reading what it asked the model, which model file answered and how the model was run. After a later update, documents still waiting for your check that nobody has acted on are validated again by the new release's rules from the model's stored reply, without asking the model again, when all three are unchanged. A rule a future release improves then reaches the documents already waiting. Documents read by earlier releases are left as they are.

## Updates

The installer is `Intern_0.1.0-alpha.18_x64-setup.exe`. Existing settings, queue records and model downloads are retained; upgrading from alpha.13 or later downloads no model.

The installer is **not Authenticode signed**. Windows may show a SmartScreen warning. Updater signatures, checksums and GitHub build provenance are verified before publication.
