# Intern v0.1.0-alpha.16

Intern is an alpha release for Windows 10 or 11, x86-64.

## Easier everyday work

- Status appears first in Queue and Completed, keeping original filenames, proposed filenames and descriptions together for copying.
- Folder settings now use the names **Queue folder** and **Completed folder**. Your existing folders stay where they are.
- The main screen and settings put common actions first. Detailed analysis and less common settings remain available when needed.
- After an update, a short summary explains what changed. Dismiss it once to return to your work.
- API-key setup has been removed. Intern uses its local models, including for installations that previously selected a hosted model.

## File handling

- If a document changes while waiting in the queue, Intern now checks approval against the version it actually began reading. This fixes an unnecessary “Analyze again” warning reproduced with a real file.
- Problems accessing a file are reported as access errors rather than incorrectly saying its contents changed.
- Files that change after reading still need another analysis before approval.

The reported warning disappeared when the user moved to local folders. These fixes cover reproduced defects in that workflow; the exact OneDrive/SharePoint behavior on that computer has not been independently reproduced.

## Updates

The installer is `Intern_0.1.0-alpha.16_x64-setup.exe`. Existing settings, queue records and model downloads are retained. Existing hosted-model selections return to local processing.

The installer is **not Authenticode signed**. Windows may show a SmartScreen warning. Updater signatures, checksums and GitHub build provenance are verified before publication.
