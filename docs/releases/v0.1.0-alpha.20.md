# ATLAS v0.1.0-alpha.20

ATLAS is an alpha release for Windows 10 or 11, x86-64.

## Intern is now ATLAS

**A**nalyze · **T**itle · **L**abel · **A**pprove · **S**tore. The window, the tray, the download page and Explorer's **Send to > ATLAS** carry the new name; Send to > Intern is removed when the update installs. The install folder, the Start menu entry, the installer's file name and the data folder (`%LOCALAPPDATA%\com.intern.app`) keep the name Intern, so this update installs over the current version in place, with your queue, settings, learned spellings and models as they were.

## Names

- **Names lead with the organization.** A name is now `date organization - subject`: `2026-10-16 Vistage International - Host Chair SOW for John Smith`, `2025-03-26 Vistage Malaysia - Employment Termination Letter for Johnny Appleseed`. The organization is one of **Your organizations** in Settings when the document names it (the most specific one you listed), otherwise the organization that issued the document, without its legal form (`Inc.`, `Sdn. Bhd.`, `ApS`). A document that names only people keeps the shape it had: `2026-12-29 Notice of Termination - John Smith`. Your organization's names were left out of names before; they now lead them, so list each of your entities in Settings, one per line.
- **A file's own name is kept when it is already right.** When the original name names the same organization and parties as the reading and its words give the same type (`Host Chair SOW` for a statement of work), its wording is used; a name already in this shape with the right date is not renamed at all. Names like `scan0001` or `IMG_1234` are ignored.
- **A missing date no longer holds a document by itself.** When the reading found no date, ATLAS uses an unambiguous date in the file's name, otherwise the file's last-edited date, and the document is "Ready with a note" that says where the date came from. Without either it waits as before. The cost: a scan or an edit saved long after the document was written is filed under that later day; the note is there to find it.
- **Other small doubts no longer hold a name either**: a type taken from the document's own title, and a description that could not be fully confirmed, which never changes the name. The local model's description is built only from what was confirmed; one a hosted model wrote itself is left empty rather than filed unconfirmed.

## Reading

- **The model reads more of each document.** The evidence ATLAS gives the local model grows by half, and a document of up to about 3,000 tokens (two or three pages) goes to it whole instead of in excerpts. On the synthetic test corpus this recovers 5 of the 12 subject terms and facts the model was not shown before, and loses none. It costs time: about 12% more model time over the corpus, about 33 seconds more for a long document on the accurate model, and 70 to 95 seconds more for a two- or three-page document now read whole. Memory use does not change.
- **The model sees the file's current name**, as a hint it cannot cite: every fact in a name still has to be found in the document.

## Confidence

- **The figure shown is how sure ATLAS is of the name**, and it can no longer read 100% beside "Needs review". It is the lower of the model's own rating and its least sure word, held under 50% while a document waits, and lower for each thing noted about it. Its colour follows the status.
- **The accurate model's gate is lower**: a reading waits when its least sure word is under 0.70, where it was 0.80. On the recorded test readings this makes 49% of the synthetic corpus ready instead of 36%, with one more wrong name filed without a check, and across every measured set wrong names among the ready ones go from 10.6% to 12.7%. Readings from the quick model still always wait.

## In review

- **Review reasons are a few words each** - "Party unclear", "No date found", "Possible duplicate" - with the explanation a click away.
- **View document** (Alt+V) shows the file inside ATLAS: PDFs and pictures as they are, everything else as the text ATLAS read, and for every file a switch to the text the model was given. It opens only the selected document's own file and runs nothing a PDF contains.
- **A quieter panel**: the document first, then what to check, then the name.

## In the window

- **A double-click on a row opens its details.** The double-click alpha.17 added was lost, or opened another row, when the queue moved between its two clicks: in the browser build over a busy queue, 1 double-click in 32 opened nothing and 16 opened a different row, whose name then had the cursor. It now opens the row the first click landed on: 48 of 48.
- **Clear queue** and **Clear completed** (which was Clear history) are in the ⋯ menu of each view. Both ask first. Clear queue takes everything not yet filed out of ATLAS and touches no file; the documents stay in the Queue folder and are not read again unless they change or you add them again.
- Copy moved into the ⋯ menu, and the toolbar's counts are plain words.

## Settings

- **Your organizations** and **Learned spellings** are explained in a sentence each, with an example. "Use on its own" is now **Always use**.

## Not yet known

- Whether the wider evidence names more documents right on real documents: the synthetic corpus measures what the model is shown, not what it does with it, and the accurate model's readings of real documents have not been taken since the change.
- Nothing in this release has been run in the Windows app's own window by a person; the window's journeys run in the browser build, and the installer, the update over an earlier release and the Send to change run in CI on Windows.

## Updates

The installer is `Intern_0.1.0-alpha.20_x64-setup.exe`. Existing settings, queue records and model downloads are retained; upgrading from alpha.13 or later downloads no model.

The installer is **not Authenticode signed**. Windows may show a SmartScreen warning. Updater signatures, checksums and GitHub build provenance are verified before publication.
