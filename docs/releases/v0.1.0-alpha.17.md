# Intern v0.1.0-alpha.17

Intern is an alpha release for Windows 10 or 11, x86-64.

## Faster, in less memory

- **The accurate model needs about 2.6 GB less memory.** Qwen3.5 9B now reads its weights where the model file lies instead of keeping a second copy of most of them. On a 16 GiB Windows test machine its memory after a document fell from 8,110 MiB to 5,491 MiB.
- **It reads documents 10–27% faster on most processors we measured**: 22–27% on recent AMD processors, 10–15% on the code path most laptops use, and no change on an Intel server processor with AMX. These are Linux test-machine measurements; PENDING-WINDOWS-SPEED.
- **The first document after Intern starts is read sooner.** The model's fixed instructions are worked out once, kept in Intern's data folder (174 MB a model, in `slots`, which can be deleted at any time) and restored at the next start, so the first document no longer waits for them: on Linux test machines its whole reading took 40% less time, the same as any later document. A saved state that fails the model's self-test is deleted and the model is tested again without it.
- **Scanned documents are read about 9% sooner** (13% on a 25-page scan) on computers with four to seven logical processors, which now read two pages at once, as computers with eight or more already did, when there is memory for it.

## Better names

- Court filings, invoices, letters and emails are named right more often: a caption's parties are read from the court's heading, the line that says where payment goes names an invoice's issuer, and an email's header says who sent it and to whom.
- When the document leaves a party in doubt — a name the model may have taken from the wrong side, a notice addressed to "all staff", a document with no issuer — Intern now holds it for your check instead of filing it. Those reasons now read **Party uncertain** and **Party missing**, and say what to check.
- **Fewer wrong names are filed without your check.** A name is now filed on its own only when the model is surer of its date and parties than before (its review gate moved from 0.7 to 0.8, by a rule fixed before the test set below was read). On 51 real public documents no rule in this release was written from, alpha.16 would have filed 7 names, 2 of them wrong; this release files 5, 1 of them wrong. More documents wait for a quick look: on Intern's synthetic test set, 28 of 77 are filed where 38 were.
- How much better the names are depends on the documents. On those 51 unseen documents this release names 19 of 45 right where alpha.16 named 18; on the five sets of real documents the new rules were written from, 137 of 259 where alpha.16 named 117. Expect the gain on your own documents to be nearer the first figure.

## Review and queue

- Evidence in review says when it is the document's own lines, and which model read the document.
- The "model unsure" reason says what to check, and no longer contradicts the confidence shown beside it.
- Analysis details stay open or closed as you left them while you move through review.
- Alt+N skips to the next document to decide, a double-click on a row opens its details, and Escape closes the More menu.
- Long queues respond faster while Intern is reading and while you type in the filter.
- Once Intern has read a couple of documents, the progress bar moves while each one is read, and the time left is shown from the start of every run.

## Updates

The installer is `Intern_0.1.0-alpha.17_x64-setup.exe`. Existing settings, queue records and model downloads are retained; upgrading from alpha.13 or later downloads no model.

The installer is **not Authenticode signed**. Windows may show a SmartScreen warning. Updater signatures, checksums and GitHub build provenance are verified before publication.
