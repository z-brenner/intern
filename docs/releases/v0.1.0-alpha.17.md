# Intern v0.1.0-alpha.17

Intern is an alpha release for Windows 10 or 11, x86-64.

## Faster, in less memory

- **The accurate model holds about 2.7 GB less memory while it is loaded**, leaving that much more for your other programs. Qwen3.5 9B now reads its weights where the model file lies instead of keeping a second copy of most of them. On a 16 GiB Windows test machine its memory after a document fell from 8,110 MiB to 5,491 MiB. It still needs about 8 GB of memory free to load; with less, the quicker model reads in its place, as before. A loaded quicker model now waits for about 2 GB more than that before it makes way, so a computer near the limit does not swap the two back and forth.
- **It reads documents 10–27% faster on most processors measured**: 22–27% on recent AMD processors with AVX-512, 10–15% on server processors limited to the AVX2 code path that laptops without AVX-512 use (Intel 12th-generation and later laptops are expected, not measured, to gain the same), and no change on an Intel server processor with AMX. These are Linux test-machine measurements. On a Windows test machine with an Intel Xeon (AVX-512, no AMX), the accurate model was about 4% faster per document: its prompt reading 11% faster, its writing 16% slower.
- **The first document after Intern starts is read sooner.** The model's fixed instructions are worked out once, kept in Intern's data folder (174 MB a model, in `slots`, which can be deleted at any time) and restored at the next start, so the first document no longer waits for them: on Linux test machines its whole reading took 40% less time, the same as any later document. On Windows this needs the path to Intern's data folder to use only English letters; under a user name with accented or other letters, the first document is read as before. A saved state that fails the model's self-test is deleted and the model is tested again without it.
- **Scanned pages are recognised (OCR) about 9% sooner** (13% on a 25-page scan) on computers with four to seven logical processors, which now read two pages at once, as computers with eight or more already did, when there is memory for it. Recognising the text is a small part of reading a document, so on the test machine a whole scan was done about 1% sooner, and a 25-page scan about 6% sooner.
- **A file dropped into a watched folder on this computer's own disk is noticed within seconds** instead of at the next scan, up to 20 seconds later. It is still queued only once it has held still for 10 seconds. OneDrive, SharePoint and network folders are scanned as before.
- **A slow computer no longer gives up on a long reading at 10 minutes.** A document the model needed more than 10 minutes to read was restarted and could never finish; it now has the queue's full 15 minutes.

## Better names

- Court filings, invoices, letters and emails are named right more often: a caption's parties are read from the court's heading, the line that says where payment goes names an invoice's issuer, and an email's header says who sent it and to whom.
- When the document leaves a party in doubt — a side the model may have read without the document saying so, a notice addressed to "all staff", a document with no issuer — Intern now holds it for your check instead of filing it. Those reasons now read **Party uncertain** and **Party missing**, and say what to check.
- **Fewer wrong names are filed without your check.** A name is now filed on its own only when the model is surer of its date and parties than before: its review gate moved from 0.7 to 0.8, by a rule fixed before the test set below was read. On 51 real public documents no rule in this release was written from, alpha.16 would have filed 4 right names and 3 wrong ones; this release files 3 right and 2 wrong. One wrong name in both is a blank invoice template, named for the date its spreadsheet's TODAY() cell shows. The new gate was chosen on these same documents, and one set of 51 cannot certify a rate. More documents wait for a quick look: on Intern's synthetic test set, 28 of 77 are filed where 38 were.
- How much better the names are depends on the documents. On those 51 unseen documents this release names 19 of 45 right where alpha.16 named 18; on the five sets of real documents the new rules were written from, 137 of 259 where alpha.16 named 117. Expect the gain on your own documents to be nearer the first figure.

## Review and queue

- Evidence in review says when it is the document's own lines, and which model read the document.
- The "model unsure" reason says what to check, and no longer contradicts the confidence shown beside it.
- Analysis details stay open or closed as you left them while you move through review.
- Alt+N skips to the next document to decide, a double-click on a row opens its details, and Escape closes the More menu.
- Long queues respond faster while Intern is reading and while you type in the filter.
- Once Intern has read a couple of documents, the progress bar moves while each one is read, and the time left is shown from the start of every run.

## Updates

The installer is `Intern_0.1.0-alpha.17_x64-setup.exe`. Existing settings, queue records and model downloads are retained; upgrading from alpha.13 or later downloads no model.

The installer is **not Authenticode signed**. Windows may show a SmartScreen warning. Updater signatures, checksums and GitHub build provenance are verified before publication.
